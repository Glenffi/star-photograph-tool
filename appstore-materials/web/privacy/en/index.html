Privacy

Privacy Policy

Your night-sky images stay on your Mac. The Mac App Store build of Nebulens requires no account and contains no advertising, analytics, or tracking.

Local Processing

RAW files, masks, Masters, TIFF files, and PNG files selected by the user are used only for preview, calibration, alignment, stacking, adjustment, and export on the current Mac. Nebulens does not upload these files.

Data Collection

The Mac App Store build does not collect or transmit personal data, device identifiers, photos, location, or usage records. It contains no third-party advertising, analytics, telemetry, or cloud-AI service.

File Access

Nebulens accesses only files and folders authorized through macOS system panels. App-scoped bookmarks for output locations, parameters, presets, and language preferences remain inside the app sandbox.

Updates & Contact

The Mac App Store provides updates for the store build. This policy will be revised before any release that changes data handling.
