# App Store 截图

当前提供：

- `zh-Hans/`：素材、堆栈、深空校准 3 张。
- `en-US/`：Assets、Stack、Deep Sky Calibration 3 张。
- 每张 `2880×1800` PNG，16:10，无 Alpha 通道。

这些截图来自当前 `v0.13.0` 直装版，用于建档和文案确认。完成 App Sandbox、
Store Bundle ID 和 1.0.0 签名构建后，应使用最终商店二进制复拍同一组画面，避免
审核截图与实际提交版本有细微差异。

上传前确认本地 `star-raw-2` 银河照片的摄影者已授权将作品用于 App Store 宣传。
没有明确授权时必须换成自有或获得书面商业授权的素材。

Apple 当前允许 Mac 截图使用 `1280×800`、`1440×900`、`2560×1600` 或
`2880×1800`，每个语言最少 1 张、最多 10 张，JPEG/JPG/PNG 均可，不能有 Alpha。
