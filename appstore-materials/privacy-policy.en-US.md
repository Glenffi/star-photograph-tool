# Nebulens Privacy Policy

Effective date: `__EFFECTIVE_DATE__`

Nebulens is a local macOS application for processing astrophotography RAW images. This policy applies to the version distributed through the Mac App Store.

## Information We Process

Nebulens requires no account and includes no advertising, behavioral analytics, or cross-app tracking. The Mac App Store build does not collect or send personal data, device identifiers, photos, location, or usage records to developer-operated servers.

RAW files, masks, Masters, TIFF files, and PNG files selected by the user are used only for preview, calibration, alignment, stacking, adjustment, and export on the current Mac. Nebulens does not upload these files unless the user independently shares them through another application.

## File Access and Local Storage

Nebulens accesses only files and folders authorized through macOS system file panels. To reuse a user-selected output location after relaunch, the app may store an app-scoped security-scoped bookmark inside its sandbox container. Parameters, presets, and interface-language preferences are also stored locally in the app container. Removing the app or its container removes these settings but does not delete images the user has already exported.

## Network and Third-Party Services

The Mac App Store build does not use an independent update server; updates are delivered by Apple through the Mac App Store. The app contains no third-party advertising, analytics, telemetry, or cloud-AI service.

## Children's Privacy

Nebulens is intended for photography and astronomical-image processing and does not knowingly collect personal information from users of any age.

## Changes to This Policy

If a future version introduces functionality that changes data handling, this policy and the App Store privacy disclosure will be updated before release.
