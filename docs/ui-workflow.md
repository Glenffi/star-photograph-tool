# Nebulens UI 工作流

本文以 Nebulens v0.14.0 的桌面界面为准。正常启动时打开 Qt 原生的羊皮纸冲印单；六阶段工作台仍可从「高级暗房」进入。

## 冲印单

### 成品与素材

1. 在「01 成品」选择「一张成片」「一张星轨」或「一组延时照片」，点「核对素材」。顶部也可以直接切换「成品」「素材」「保存」。
2. 在「02 素材」点「导入文件」或「导入文件夹」加入 RAW，也可以把 RAW 拖入窗口。「选用素材」显示选用张数 / 导入总张数；点「管理素材」进入高级暗房排除、恢复或移除素材。
3. 选「一张成片」时，在「拍摄对象」中选「星景」「天地分离」或「深空天体」。「星景」按选用帧数自动选择单张精修或银河星景堆栈；另两种不会因为只选用 1 张就改走单张精修。星轨、延时不显示「拍摄对象」。

| 冲印单选择 | 选用素材门槛 | 对应处理 |
|---|---:|---|
| 一张成片 → 星景 | 1 张 RAW | 单张精修，不对齐、不堆栈 |
| 一张成片 → 星景 | 2 张以上 RAW | 银河星景堆栈：质量评估、星点对齐、堆栈和收尾 |
| 一张成片 → 天地分离 | 2 张以上固定机位 RAW | 天空对齐堆栈，地景原位合成；可用「地景设置」打开高级暗房的「合成」阶段 |
| 一张成片 → 深空天体 | 2 张以上 Light RAW、完整校准来源 | 「补齐校准」打开高级暗房的「校准」阶段。Dark 和 Flat 分别使用至少 3 张 RAW 或一个 `.spmaster`；以 RAW 生成 Master Flat 时还需 Bias 或与 Flat 同曝光的 Dark Flat，详见[深空校准交互](#深空校准交互) |
| 一张星轨 | 3 张以上同尺寸、固定机位 RAW | 在原坐标累积 Lighten/Comet 星轨，不做星点对齐 |
| 一组延时照片 | 3 张以上 RAW | 逐帧降噪、编号保存图片序列，不生成视频 |

### 保存与冲印回执

1. 点「交付设置」进入「03 保存」，确认「文件格式」为「TIFF · 16 位」或「PNG · 8 位」，并核对「保存到」。未保存过输出偏好时使用个人目录下的 `Nebulens/Output`；用「选择目录…」可改选现有目录。
2. 满足素材、校准和保存设置后，点「保存成品」。冲印单显示后台任务的阶段和进度，处理和保存是同一个任务，无需另点导出。处理中可浏览预览，但不能修改素材或参数。
3. 完成后「冲印回执」显示实际交付张数和「实际保存位置」，不是任务开始前预填的目标位置。单张精修、堆栈和星轨交付 1 个图像文件，「打开目录」打开它的父目录；延时交付一个新的序列子目录及实际写出的张数，「打开目录」直接打开该子目录。

- 单图正式保存或从高级暗房再次导出时，如目标文件名已被占用，会在扩展名前尝试 `_2`、`_3` 等后缀。延时每次在所选目录下新建子目录，不复用上一单的目录。已有文件不会被覆盖。
- 点「取消」后显示「正在取消…」，等当前任务停止。取消或失败不会产生本次成功回执；若已有延时帧完整写出，它们仍保留在该次任务的子目录。检查提示后可点「重试」，不会从上次的帧号续跑。
- 「重新开单」清空当前项目的素材、校准来源、预览和回执，回到「成品」；不删除已保存的成品。需要在回执后继续调整当前项目时，从「视图 → 高级暗房」进入。

### 印样与纸面光影

- 未导入 RAW 时右侧是「示例印样」（[照片出处](../THIRD_PARTY_NOTICES.md#bundled-sample-proof)）。导入后可查看当前素材的预览，正式处理后可查看结果印样。点印样或「查看大图」在中性背景查看预览；点「返回冲印单」关闭大图。大图使用预览图，并非完整分辨率检查；细节和前后对比请在高级暗房查看。
- 顶部「纸面光影」控制可见纸面的常驻光影，不需要移动鼠标触发：「柔光」为默认，每 14 秒一循环；「流光」每 9 秒一循环；「静止」停用动效。检测到系统减弱动态效果（如 macOS 减弱动态效果或 Windows 关闭界面动画）时自动选中「静止」并禁用光影选择；解除后恢复原选择。
- 打开中性背景大图、切到高级暗房、隐藏或最小化窗口时，纸面动效暂停。光影只绘制在纸面、卡纸和阴影上，不会叠加到照片像素或写入文件。

## 高级暗房

### 切换工作区

在冲印单编辑时点「高级设置」，或通过「视图 → 高级暗房」进入。冲印单的「管理素材」「补齐校准」和「地景设置」会直接打开相应阶段。点暗房工具带的「返回冲印单」或「视图 → 冲印单」，回到同一个项目；不会重新导入或清空素材。

暗房顶部 MODE 可显式选择单张精修、银河星景、深空天体、天地分离、星轨合成或延时序列。切换场景会应用任务的参数基线、保留素材；与当前设置不一致的上次成片可以查看，但不能作为当前结果导出。

### 顶部命令

- 64px 工具带包括 Nebulens 品牌、返回冲印单、MODE 场景、项目摘要、导出、处理/取消与溢出菜单。
- 导入文件、导入目录、清空项目、设置、更新、快捷键与关于收进溢出菜单；胶片带 `+` 是主导入入口。
- 主操作使用琥珀金属色；其他命令均为深色描边或幽灵按钮。

### 流程状态

左侧的素材、校准、对齐、合成、调整、输出按场景显示，不适用的阶段会隐藏。状态栏顶部 2px 进度线和处理按钮跟随后台处理的百分比；点原位的「取消」请求停止。失败或取消后，可回看上次有效结果（如有），但它不会作为本次成品交付。

### 工作台布局

- 阶段栏：96px 编号文字导航，不使用场景插画图标；已完成、当前和警告状态使用不同状态点与边框。
- 预览区：暗房边距、低亮度浮动工具条、适应/100%/缩放、结果返回、灰点、蒙版与同坐标滑动分屏。视图状态按内容键保存最近 50 条。
- 胶片带：底部 112px 水平 Light 素材列表，保留排除、参考帧、右键菜单与 5 秒撤销。
- 参数栏：右侧只显示当前阶段内容；调整阶段显示预设和 400ms 快速预览参数，输出阶段显示文件与历史结果。

### 星轨合成交互

- 选用同机位、同尺寸的 RAW。程序先排列拍摄顺序（规则同延时序列），再保持相机坐标累积亮轨，不执行星点对齐。
- “彗星拖尾”0% 使用逐像素逐通道 Lighten。1–100% 把强度映射为时间半衰期：数值越大，较早轨迹衰减越快；“反转彗星方向”只在强度大于 0 时启用。
- 帧间光度匹配默认运行，使用首帧稀疏参考样本估计共享曝光增益和 RGB 背景偏移，减少薄云或天空亮度漂移在 Lighten 中抬高整片背景。
- “保护固定地景”默认开启。程序从序列中间帧的相机预览检测地平线，失败时回退到首帧线性亮度；天空进入星轨累积，地景在原坐标使用在线均值降噪，内存不会随帧数增长。
- 星轨场景隐藏对齐、普通堆栈、κ、质量淘汰和缩星。调整彗星强度或方向需要重新累积全部帧；降噪、改机色彩、去雾和拉伸仍可使用有界快速预览。

### BCF 改机色彩还原

- “BCF 改机色彩还原”位于“调整”页，默认关闭，明确与普通相机的常规白平衡区分。
- 开启后可使用自动灰点，也可在完成一次正式处理后点击吸管，从处理前预览中选择应为中性的天空区域。十字标记表示当前灰点，换素材、参考帧或场景会自动失效。
- 校正强度为 0–100%；它对单位增益与完整灰点增益连续插值，适合在“完全中性”和“保留部分改机暖色”之间取得平衡。
- 预览点击只保存归一化画面坐标；2400 px 快速预览和完整导出都会回到各自的线性 RGB16 缓存，以同一相对邻域重新计算中值，不读取显示曲线后的 8-bit 颜色。
- 色彩还原位于降噪、去雾和拉伸之前；处理进度会显示自动/手动模式、强度和实际 RGB 增益。
- 天地分离的自动模式只从天空蒙版内取样；手动模式由用户明确指定中性区域。两种模式的增益都应用于完整线性 RGB，避免地景与天空在边界处产生不同白平衡。
- 黎明、极光、强气辉或用户希望保留环境色时，应使用手动灰点和较低强度，或保持关闭。

### ACR 风格基础调整

- “调整”页的“基础调色”按白平衡、光线、颜色和细节分组。全部参数的中性值为 0，不再增加一个重复的总开关；任一滑块离开 0 即进入快速预览。点击处理以及正常关闭窗口时都会保存当前参数，自定义预设则显式保存整组数值。
- 色温和色调范围为 `-100..100`。色温是线性 sRGB 工作空间中的相对冷暖偏移，不代表相机元数据中的绝对 Kelvin；界面因此使用“色温偏移”名称。
- 曝光范围为 `-5.0..+5.0 EV`，内部以十分之一 EV 保存，预设和不同平台间不会因浮点序列化产生漂移。对比度、高光、阴影、白色、黑色、自然饱和度和饱和度范围为 `-100..100`。
- 明暗控制先计算联动亮度曲线，再按原 RGB 比例重建颜色；白平衡、自然饱和度和饱和度造成通道越界时，程序围绕目标亮度收敛色度，不分别硬裁切 R/G/B。这样可降低强拉伸后天空渐变出现彩色断层的风险。
- 自然饱和度优先增强低饱和区域，已经鲜艳的星云和城市辉光受到更多保护；饱和度则统一改变全部颜色。两者可以叠加，但高数值仍应检查是否超出线性 sRGB 色域。
- 锐化范围为 `0..100`，默认 0。算法只处理亮度高频，设置噪声阈值并保护深阴影与亮星核心，再按目标亮度重建 RGB。单张高 ISO RAW 建议先降噪，再从 10–35 开始；锐化不会替代降噪或反卷积。
- 正式管线顺序为：改机还原 → 降噪 → 去雾 → 自动拉伸 → 基础明暗/色彩 → 地景细节 → 亮度锐化 → 星点去紫边 → 缩星。去紫边可独立启用，只修正相对星核向外突增的色度；同时启用缩星时不会重复校正。基础曝光放在自动拉伸之后，避免百分位自动归一化抵消用户调整。
- 星空延时当前逐帧走独立的时域输出管线，因此隐藏基础调色；其余单图结果场景都共用 `FinishingPipeline`，快速预览与完整导出的算法和顺序一致。

### 天地场景的背景校正

- “检测地景”先在与中央浏览预览同尺寸的图像上生成自动硬蒙版。青灰代表天空、暖琥珀代表地景；检测结果本身不会被当作用户编辑，正式处理仍可在 RAW 尺寸重新检测。
- 自动结果漏掉山体、建筑或树线时，“修补地景”笔刷只提供橙色地景种子，不直接涂改最终蒙版。每次松手后，后台任务在笔迹附近运行边缘引导分割，沿颜色和亮度梯度重新求出连续边界；撤销会重新计算剩余笔迹，重置则恢复最初的自动结果。
- 精修结果以有界预览分辨率保存并进入处理签名。正式堆栈前先用最近邻放大硬分类，再按用户羽化半径在缩小工作面模糊一次，避免预览和 RAW 阶段重复羽化，也避免把软边阈值化后产生新的轮廓。
- 精修蒙版绑定生成它的照片。若处理仍使用自动参考帧，该照片会固定为正式参考帧；用户改选另一张参考帧时旧精修自动清除，必须重新检测，防止把 A 帧山脊坐标套到 B 帧。
- 笔迹不要求贴着轮廓画，只需落在漏检地景内部。透明枝叶、树冠孔洞、雾中弱边缘或地景与天空颜色非常接近时，图像本身缺少可吸附梯度，仍应改用完整用户蒙版。
- 星空对齐会同时移动整张 RGB，因此程序从羽化蒙版另建一张内缩的二值天空有效区，并对每个源帧使用相同的 Affine/Homography 变换。参考有效天空中没有被源有效区覆盖的位置会在进入天空缓存前标成无效，防止移动后的树林或山体堆出第二层轮廓；软蒙版只负责最终融合。
- 开启天地分离后，自动拉伸的低频背景模型只从天空蒙版的可靠内部取样。山体、建筑和湖面不会参与天空底色估计，避免粗网格把地景轮廓误当作光污染梯度。
- 没有足够天空样本的网格由最近的有效天空模型补齐，再做中值平滑；全地景或无有效天空的异常蒙版会安全跳过背景中和，不使用地景代替天空。
- 天空色偏校正沿羽化蒙版使用平滑缓入缓出，并采用保守强度。完全地景区域保持不变，真实雾霾、城市辉光和气辉会适度保留，不把地平线强行处理成中性灰。
- RGB 背景模型先转换为共享亮度与有符号色度偏移。色度连续减去，不再让 R/G/B 分别通过 `max(0, model-target)` 的硬拐点；亮度只在高于稳健背景目标时通过宽肩部渐进校正。这样强 Arcsinh 拉伸不会把三个不同的通道阈值放大成红、绿或蓝色环带。
- 该步骤只改变低频 RGB 背景，不执行锐化或反卷积。单张 RAW 已有的失焦、空气散射、镜头像差和曝光内星迹不会由背景校正恢复。

### 延时序列交互

- 整组 RAW 都有拍摄时间时按时间升序排列，同秒按自然文件名升序；任一帧缺时间，整组改按自然文件名升序。例如 `frame2.dng` 拍得比 `frame10.dng` 晚，但 `frame3.dng` 缺时间，输出仍依次对应 `frame2`、`frame3`、`frame10`。每张 RAW 写出一张保留原文件名的编号 TIFF/PNG，不生成视频。
- 预分析进度分为元数据与资源检查、RAW 解码/星点检测、邻帧对齐、蒙版与光度分析；同一源帧在多个滑动窗口中复用时，归一化成功/跳过统计只计一次。
- 邻帧对齐、窗口降噪和逐行导出都会检查取消状态。取消后已完整写出的序列帧保留，未完成的帧不作为成品交付。
- 3 帧窗口速度更快，5 帧窗口随机噪声抑制更明显；序列首尾自动使用能取得的相邻帧。
- “动态内容保护”默认 75。提高后，云层、草木、车辆灯光等与当前帧不同的局部区域会减少邻帧混合；静止区域仍使用完整时域降噪。该判断共用一张亮度引导图，不会造成 RGB 通道错位。
- “固定地景保持原位”开启时，天空按星点运动对齐，地景在原坐标做时域统计，最后沿自动地平线融合。
- 跨帧亮度与色偏平滑自动运行，没有额外开关。它只校正 5 帧邻域中的孤立跳变，并限制单次调整幅度，连续变亮或变暗的真实时间趋势会保留。
- 完成后，冲印回执指向本次序列子目录；高级暗房可查看中间帧的前后对比（偶数张时取靠后的一张）。对当前有效的延时结果使用暗房的「导出」只打开本次序列目录，不写出单图或重复导出序列。

### 深空校准交互

- 底部胶片带只管理 Light；Dark、Flat、Bias、Dark Flat 在“校准”阶段管理，避免不同用途素材混入参考帧和质量评分。每个角色可选择至少 3 张 RAW，或一个 Nebulens `.spmaster` 主帧，二者互斥。
- Dark 与 Flat 始终必需。由 RAW 生成 Master Flat 时，使用 Bias 或与 Flat 同曝光的 Dark Flat 校准偏移；已经校准并按 CFA phase 归一化的 Master Flat 不重复搭配 Dark Flat。外部 Master Dark 若声明已经减去 Bias，则 Light 校准还必须提供 Bias，且程序只减一次偏置。
- 每个 RAW 组至少 3 张才开放“开始处理”，界面建议 10–20 张。勾选“保存本次生成的 Master”后，只保存本次实际由 RAW 生成的角色；所有来源和最终组合均通过后，临时目录才整体重命名到输出目录的 `Masters/时间戳`，失败不会留下半套主帧。
- 数量齐备后，参数栏明确提示会在处理开始时执行自动预检。RAW 只读取头信息，`.spmaster` 只读取结构化头，一次列出角色、相机、尺寸、ISO、曝光和重复路径问题；正式加载还会校验完整像素的 SHA-256，损坏文件不会进入校准。
- Dark 必须与 Light 同相机、ISO 和曝光；Flat 必须同相机、ISO；Dark Flat 必须匹配 Flat 曝光；Bias 必须同相机、ISO，并满足本组 Light 推导出的最短曝光上限。所有 Master 还会校验有效传感器区域、Bayer 排列、饱和值和内部校准状态。
- 预检错误使用聚合对话框显示受影响数量和示例文件；仅有建议时继续处理，并在完成后以非阻塞信息框提示。命令行报告同步写入 `calibrationPreflightWarnings`。
- 校准路径只在当前会话保留，不写入预设或 `QSettings`，避免移动硬盘或拍摄目录变化后静默引用旧文件。
- 生成或加载 Master Bias/Dark/Dark Flat/Flat 时，状态栏显示当前校准阶段；实际开始星点对齐后改为对齐进度。

### 深空高光保护

- 自动 Arcsinh 拉伸把稳健高光点映射到约 85%，更亮的星云核心继续使用剩余输出空间，不会把所有超过白点的样本压成同一个亮度平台。
- 高饱和发射星云可能在亮度仍有余量时先让红色或蓝色通道越界。程序从 90% 输出开始使用柔性肩部，先同比例压缩 RGB 保留色相；若完全保色会造成暗色核心，则至少保留 65% 的目标亮度，再只收敛无法装入线性 sRGB 的色度。
- 最终通道上限为 99.5%，因此 TIFF 保留后续编辑余量。该步骤只处理即将越界的高光，不改变普通星云、背景和 90% 以下星点。

## 堆栈算法选择

参数栏会随当前算法显示一段简短说明，并且只在 Kappa-Sigma 模式启用 κ 控件。

| 算法 | 主要特点 | 建议场景 |
|---|---|---|
| Median | 对飞机轨迹、热像素等异常值稳健，但信噪比利用率低于平均值 | 5 帧及以下，或素材质量差异较大 |
| Mean | 信噪比与细节利用率最高，但异常轨迹和坏点容易残留 | 素材干净、曝光一致的序列 |
| Kappa-Sigma | 迭代剔除超出 κ 阈值的像素，稳健性与细节较均衡 | 6–15 帧的一般银河和深空序列 |
| Winsorized | 限制极端值后求均值，长序列中兼顾异常值抑制与信噪比 | 15 帧以上的长序列 |

## 处理前后比较

`ProcessingWorker` 在裁切共同有效区域后、执行降噪/优化/地景细节/缩星前，生成最长边 2400 px 的 8-bit 预览。处理前和处理后共享固定的完整 16-bit 显示范围及 Arcsinh 映射，避免两侧各自自动拉伸掩盖真实亮度和对比度变化。GUI 只保存这张有界预览和最终 16-bit 结果，因此不会引入第二份完整 RGB16 内存峰值。

比较模式包括：

- 处理前：完成堆栈、光度匹配和裁切后的基础结果。
- 处理后：完成当前全部收尾算法后的结果。
- 分屏：同一张画面左侧显示处理前，右侧显示处理后。拖动分割线可在相同坐标查看变化；用 100% 和滚动进一步检查细节。

用户从结果切回单张 RAW 后，浮动工具条显示“结果”，也可按 R，无需重新处理即可返回最近成片和原检查位置。

## 参数快速预览

支持快速预览的单图正式处理完成后，暗房保留最长边 2400 px 的线性 RGB16 收尾前缓存及对应天地蒙版。调整降噪、改机色彩、去雾、拉伸、基础调色、锐化、地景细节、去紫边或缩星参数时，应用等待 400 ms 后在后台只重跑收尾算法；继续拖动控件会取消或丢弃过期结果。对齐、堆栈、参考帧、校准帧和天地合成参数改变时不会使用该缓存，延时也不走此预览流程。

手动再次导出当前有效的完整单图结果由独立后台任务完成，不在 GUI 线程执行 PNG 压缩或 TIFF 写盘。导出期间锁定素材与参数编辑，主按钮原位变为「取消」；完成后继续保留内存中的正式结果供预览和再次导出。

快速结果在浮动工具条持续显示“快速预览”和“完整导出需重新处理”，切换 RAW 后仍可通过“结果”或 R 返回。快速预览只用于判断参数方向，不开放导出；用户必须点击“处理”生成完整分辨率结果。处理前、处理后和分屏继续使用同一显示范围，避免自动曝光掩盖参数差异。

刷新快速预览时会保留处理前/后/分屏模式、适应或手动缩放以及滚动位置。缩星对暗弱小星的改变在整图适应状态下可能小于一个显示像素，因此开启缩星后状态栏会报告实际处理星数，并提示在 100% 下复核；滑块刷新不会再把 100% 视图重置回适应窗口。

## 结果与报告

- 当已有结果与当前素材、场景或处理参数不再一致时，清除当前回执并禁用再次导出；旧成片仍可在高级暗房查看，磁盘上已写出的文件不受影响。
- 高级暗房「输出」页的处理报告列出成品尺寸、实际帧数和文件位置；视场景和处理步骤，还可查看对齐 RMS/P95、网格覆盖、模型选择、筛选、光度增益、天地蒙版和堆栈耗时。
- 输出页从当前输出目录和旧版默认目录最多列出 5 个最近的成片 TIFF（含 `_stacked`、`_single` 或 `_star_trail`）。后台使用 libtiff 读取 16-bit RGB，再生成最长边 2400 px 的只读预览；历史文件不会获得当前结果的导出资格。

## 离屏视觉检查

应用支持开发用的 `--screenshot=<path>` 参数。以下以 macOS 手动构建目录 `build` 为例，可分别截取默认冲印单和高级暗房：

```bash
QT_QPA_PLATFORM=offscreen \
  ./build/StarProcessor.app/Contents/MacOS/StarProcessor \
  --window-size=1440x900 \
  --screenshot=/tmp/nebulens-print-order.png

QT_QPA_PLATFORM=offscreen \
  ./build/StarProcessor.app/Contents/MacOS/StarProcessor \
  --workflow=assets \
  --window-size=1440x900 \
  --screenshot=/tmp/nebulens-darkroom.png \
  /path/to/first.ARW /path/to/second.ARW
```

启动参数中的 RAW 文件会直接导入；`--scene=deep-sky` 可指定场景，但不会单独切入暗房。`--inspector=output` 或 `--workflow=output` 可进入暗房的「输出」页，`--history=/path/result.tiff` 可检查历史预览。可加 `--language=zh_CN` 或 `--language=en_US` 检查双语界面，不改写已保存的语言偏好。

视觉复核时，可检查 920×540 窗口下限、常用窗口尺寸和高 DPI 缩放，以及横竖印样、长路径回执和处理结果分屏。截图只记录一个时刻；要核对 14 秒和 9 秒的常驻动效、系统减弱设置，以及「打开目录」是否指向实际成品，请启动应用进行交互检查。自动化回归命令见 [README 的冲印单定向测试](../README.md#冲印单定向测试)。
