# 星炼 v0.12.0 界面重设计实现说明

> 状态：Qt 实现完成，等待最终用户验收
> 原型：`star-photograph-tool-design/web-prototype-v2`
> 交互确认稿：`web-prototype-v2/交互细节确认稿.md`

## 产品名称

用户可见名称改为 **星炼**，含义是把校准、对齐、堆栈和调色后的星空素材炼成最终成片。

为保证已有用户升级和数据兼容，以下技术身份暂时保留：

- CMake target 与可执行文件内部名 `StarProcessor`；
- `QSettings("StarProcessor", "App")` 设置空间；
- `/starprocessor/update.json` 更新入口与旧安装包文件名协议；
- `.spmaster` 扩展名、文件魔数和校验结构；
- macOS Bundle ID `com.starprocessor.StarProcessor`。

macOS `CFBundleDisplayName`、窗口标题、About、更新对话框、Master 文案和默认输出目录均显示“星炼”。旧默认输出路径会迁移到 `~/星炼/Output`，历史列表仍同时扫描旧目录。

## 工作台结构

```text
64px 顶部工具带
├── 新 Logo 与“星炼”字标
├── MODE 场景选择
├── 当前项目摘要
└── 导出 / 开始处理 / 更多

主工作区
├── 96px 六阶段导航
├── 中央画布
│   └── 112px Light 素材胶片带
└── 368px 阶段检查器

28px 任务状态栏
```

六阶段为：素材、校准、对齐、合成、调整、输出。阶段和场景使用编号与文字，不使用装饰性图标。单张精修隐藏校准、对齐和合成阶段。

## 已实现交互

### 场景与阶段

- 顶部 MODE 下拉切换六类场景；不再在素材面板重复展示图标场景入口。
- 左侧阶段点击后，右侧检查器使用 200ms 淡入切换。
- 阶段状态支持未完成、已完成、警告和当前状态。
- 素材、校准、对齐、合成在同一参数模型上切换可见分组，不复制算法状态。

### 素材胶片带

- Light 素材改为底部水平胶片带。
- 缩略图保持单选、参考帧、排除、右键菜单和 5 秒撤销行为。
- 选中项使用琥珀多层边框；排除项降低透明度。
- 素材阶段显示可用数量、场景门槛和参考帧真实状态。

### 参数检查器

- 标签页隐藏，阶段导航成为唯一主导航。
- 检查器标题显示阶段编号和英文缩写。
- 预设仅在调整阶段显示。
- 所有 `inspectorRole=value` 数值统一固定 54px，并使用等宽字体右对齐。
- 滑块标签继续使用 88px 统一宽度，轨道不再随数值长度移动。
- 参数快速预览防抖由 200ms 调整为确认稿规定的 400ms。

### 中央画布

- 保留 RAW 后台预览、内容级缩放/滚动状态、灰点和蒙版编辑。
- 分屏从“左右并排两张完整图”改成同坐标 Before/After 滑动分割。
- 拖动中线可在 5%-95% 范围内调整分割位置。
- 蒙版改为青灰天空和暖琥珀地景，不再使用高饱和蓝绿。
- 选点标记改用低饱和青灰。

### 任务反馈

- 开始处理按钮显示真实百分比，并保持可请求取消。
- 处理中主按钮改为深灰状态，不使用红色危险按钮。
- 状态栏继续显示 2px 真实进度线。
- 处理完成后标记对齐、合成、调整和输出阶段，不强制跳到输出。

## 未伪造的原型项目

以下内容没有用占位实现冒充完整功能：

- 顶部全局撤销/重做：当前没有统一命令栈，因此未放入正式界面；素材撤销和蒙版撤销继续保留在各自上下文。
- 导入时质量分数：质量评估发生在处理阶段，项目模型尚未持久化逐帧分数，因此胶片带不显示虚构分数。
- 循环粒子、背景光球和持续霓虹动画：不符合暗房工具定位，未实现。
