# 自动镜头横向色差校正

## 解决的问题

镜头横向色差会让画面外圈的恒星在红、绿、蓝通道中落在略有不同的位置。多帧按亮度星心对齐后，这类亚像素偏移仍会保留，并可能在堆栈中形成有方向性的紫色或青色星缘。

本模块只校正这种随离光轴距离近似线性增加的几何偏移。亮星宽紫晕、焦点前后的轴向色差、大气色散和真实星色不属于该模型。

## 自动估计

1. 从参考帧线性 RGB16 提取亮度，并在全画面均衡检测星点。
2. 排除饱和、过宽、拖线、过暗和靠近光轴的星点。
3. 排除过近邻星，并在每颗星的局部窗口内用环形背景 MAD 建立噪声门限，再分别计算 R/G/B 亚像素质心。
4. 以绿色为几何基准，把红、蓝偏移分解为径向和切向分量。
5. 拟合 `通道偏移 = 全局平移 + 径向尺度 × 离轴坐标`。全局平移只作为干扰项剥离，不把大气色散或通道常量位移误当成镜头径向色差。
6. 用 MAD 剔除离群星；只有至少 20 个内点、12 个外圈内点、三个象限、五个角度扇区、70% 内点率、有限边缘位移，以及相对“不校正”基线至少 10% 的径向残差改善同时成立时才启用对应通道。

模型的 `sourceScale` 表示输出像素应从源通道的哪个径向位置采样。大于 1 表示该通道原本向外展开，校正时向更外侧取样以把结构拉回绿色通道。

## 处理链与画质保护

- 参考帧只校正一次；同一序列的其他帧复用参考帧模型，避免噪声让每帧产生不同尺度。
- 源帧把镜头色差校正和 Affine/Homography 对齐合并到同一次双线性重采样中，不额外模糊星点。
- 天地分离中的原位地景使用同一模型，保证天空与地景边界两侧颜色几何一致。
- 最终共同有效区域会逐个变换验证 R/G/B 三组源坐标；单张模式也会裁掉通常只有 1–3 px 的径向采样边界。
- 检测失败或证据不足不是错误，处理链会保持原像素不变。

## 验证

`StarProcessorPipelineRunner` 默认启用自动校正。使用 `--no-auto-lens-ca` 关闭后，可在同一 RAW 上生成 A/B 结果。`pipeline-report.json` 中记录是否应用、红蓝通道测量星点/内点数量、边缘位移、径向残差和切向残差。

自动化测试包含已知红蓝径向偏移、无色差和单侧星场三类合成图。发布前还应在 100% 比例检查画面中心与四角，确认彩边收敛且真实星色没有被中和。
