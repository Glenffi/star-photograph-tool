# 山脊示例与可重开的冲印单

1. 用获准在本机使用的真实 RAW，按同一参考帧生成单张、普通堆栈和天地分离。原计划的湖边素材不在本机，本次改用用户指出的 NAS 序列；记录实用的素材名，不把其他景色标为湖边。无可用帧时不交付虚构对照。
2. 三份山脊印样使用参考帧里的同一矩形、相同显示变换与倍率，按各成品的裁切偏移换算坐标。生成时不上传照片、不动原片，分享开源代码不等于授权分发素材。
3. 冲印单可保存为一个版本化文件，再由文件菜单重开。恢复素材顺序、选片/排除、参考、校准、参数、输出设置与绑定参考帧的手修蒙版。只关联 RAW，不保留可冒充新结果的成片或回执。
4. 输入目录搬家可整目录重定位；取消、坏文件或不支持的版本不替换当前工作。构建、实测和交付均在本机进行。
