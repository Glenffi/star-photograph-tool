# 本机验收

操作方法与可独立重跑的命令见[冲印单与山脊示例](../../docs/print-order-files.md)。常规 CTest 不依赖私有照片或网络。可选的真实示例重放测试需自行提供本地单据和基准 TIFF。

2026-11-27 的 macOS 验收：18 组 CTest 通过；包含冲印单编解码、两次独立启动之间的保存及重关联、三路比较生成器和原生窗口检查。另用同一机位 9 张真实 RAW、同一参考帧、同一组 7 张通过对齐的素材生成三路对照。重开单据后经图形界面正式导出，与原管线的 5900×3931 线性 RGB16 TIFF 逐像素相同。暗山上的主要问题是自动掩码跟随屋顶，故最终对照明确注明使用修补蒙版；原自动结果另存用于对照。本轮未使用 GitHub Actions，也没有做 Windows 实机验证。
