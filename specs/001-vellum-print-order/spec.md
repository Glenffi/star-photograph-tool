# 羊皮纸冲印单与成片可靠性

功能分支 `feat/vellum-print-order` · 2026-11-26 · 用户已选定并授权实施。基线为 0.13.0 的 `2e80192`。

## 用户场景

- **US1 / P1 · 新手出片**。启动后先选一张成片、一张星轨或一组延时照片，核对真实 RAW，再选格式和输出目录。首张可精修，星轨和延时仍需至少三张。深空显示还缺哪种校准来源并能补齐，带前景的星景可启用天地分离。
- **US2 / P1 · 可信交付**。回执提供本次实际落盘的文件或目录。取消、失败和清空后不会把旧作品当作新结果。两次同时保存不得覆盖已有成片。
- **US3 / P1 · 暗房体验**。纸面有静置时持续的侧光，柔光、流光和静止可选；系统减弱动态效果、窗口隐藏和看大图时停止环境动效。照片本身保持原色及位置。原有蒙版、精修、选片和同位置比较均有可返回的入口。
- **US4 / P2 · 有效的算法和诊断**。竖幅星轨、短曝光 Dark Flat、星场覆盖、交集裁切、延时排序与磁盘预检遵循产品约定。中文和英文得到相同任务阶段。

## 功能需求与验收

| 编号 | 触发与预期 |
|---|---|
| FR-01 | 默认进入原生冲印单。三个步骤允许返回且保留当前选择；只有真实的素材和校准来源满足条件才能生成。 |
| FR-02 | 点击生成提交后台任务，进度可取消；成功提供本次真实路径，延时打开本次子目录，单张结果按 1 个交付件计数。 |
| FR-03 | 原型纸纹与中性印样相互隔离；静置时动态光影可见，选静止或操作系统要求减弱动画时停止。无交互时照片像素保持稳定。 |
| FR-04 | 同目录同时处理/导出得到不同路径。取消和失败不得破坏此前成片（R01）。清空后清掉 Light、校准来源、修补蒙版、结果缓存与资格，同路径替换 RAW 须重新处理（R02）。 |
| FR-05 | 方向 6/8 的同尺寸星轨能按正确竖幅输出（R03）。对已知平移的中等密度星场分别均衡拟合与留出验证集（R04）。1 ms Flat 配 10 ms Dark Flat 必须拒绝（R05）。共同有效区不足时明确反馈（R10）。 |
| FR-06 | 同一设置在快预览与正式收尾中的蒙版和地景细节一致（R06）。保留检查位置；胶片带/参数页的自动参考一致，预设开关与实际值一致。 |
| FR-07 | 延时 CLI 拒绝无法生效的收尾选项（R07）。报告中的帧顺序、参考位置、源路径及编号相互对应（R08）。预估临时与输出空间，按卷分别或合并检查（R09）。 |
| FR-08 | 六种场景可进入；单张自动精修不覆盖明确指定的星轨、深空和延时意图。真实任务阶段独立于翻译文案。 |
| FR-09 | 排序与发布标签文档反映实现。中文注释说明关键契约，双语词条随程序发布。 |

## 成功标准

1. 在独立目录使用正常 CMake 入口构建，CTest 全部通过。使用带已知时间/方向的 DNG 对照正式管线复测原问题。
2. Qt 客户端执行从冲印单到真实 TIFF/PNG 的操作，验证重新开单、目录交付、失败状态和同位置比较。
3. 在小窗口和双语界面检查实际布局。样机中的演示写盘、假素材和模拟进度不得进入正式处理逻辑。
