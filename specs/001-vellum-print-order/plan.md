# 实施计划

沿用 C++17、Qt 6 Widgets、LibRaw、libtiff 和 CMake。保留现有 core → workers → UI 的依赖方向。原有 constitution 是通用模板，本次按仓库贡献规范、用户确认的冲印单和已记录的验收条件执行。

1. 原生 `PrintOrderPanel` 呈现单据，把素材、输出、任务和回执交给 `MainWindow` 协调。现有暗房作为可返回的高级视图，两个视图操作同一项目。纹理随包分发。
2. 在文件交付、星点划分、曝光比较和磁盘估算边界收敛规则，代码和样片工具复用。worker 输出阶段枚举，界面只翻译显示。
3. 输入、参考帧、处理签名、使用中的结果及成品路径分清生命周期。正式与快速收尾共享有效选项，签名仅用于判定像素是否需要重算。
4. 回归测试优先覆盖真实失败案例。最小窗口验证、英文词条、图片序列回执与实际上机核验归入同一次验收。
