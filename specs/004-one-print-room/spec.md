# 一张冲印单

第一次打开 Nebulens 的人应能从印样辨认三种交付物，然后用自己的照片走完导入、调整和保存。高级参数是当前订单的一部分，不需要重新学一套软件。本次不改变相机解码、处理算法、文件格式或匿名报告契约。

| 操作 | 用户应该看到的结果 |
|---|---|
| 启动原生客户端 | 从系统窗控所在位置到纸面的视觉连续；保留原生关闭、最小化、缩放/全屏、拖动和可访问性，没有一整条额外深色品牌带。 |
| 在空单上点成片、星轨、延时 | 三种真实印样立即变化。延时展示同一段拍摄的多张顺序帧，可直接选帧；减少动效时仍能辨认这三种交付物。 |
| 导入、切换产品或重开单据 | 演示有标记，原片、待读取和正式/快速结果不混用；不以演示图或上次结果冒充本次成品。 |
| 修改曝光，或进入更细的校准、蒙版和调整 | 常用参数在单上就能改，与参数附页共用真实值。附页与纸面同窗、同订单、同页首；返回保留原步骤、素材及检查状态。 |
| 重看印样、打开回执、文件或设置 | 应用的命令、参数表和对话框保持同一种印刷层次，照片/局部对照保持中性，不用纸纹给照片着色。 |

不公开私人 NAS 素材。演示资源须能随开源安装包再分发，作者、授权和加工方式可追溯。Windows 或其他平台没有实机核验的项目单独注明。
