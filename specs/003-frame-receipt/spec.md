# 能解释用片的冲印回执

成功交付后，用户先看到交付件数和实际采用的素材数，再按需查看用片明细。回执只描述本次正式处理，不把快预览、重新开单、取消或失败计为交付。

1. 区分片列总数、交给处理程序的张数、实际采用、手动排除和单张精修时未提交的其他照片。质量筛除、解码失败、检星不足、对齐未通过及重采样失败应给出各自的原因。
2. 明细可与本次真实参考帧并排查看原片预览。不同目录的同名照片不能互相覆盖，查看不改变主窗口选片、参考、参数或导出资格。延时编号采用实际写盘顺序。
3. 只有主动导出才写匿名 JSON。仅包含固定机器码、帧序号和必要数值，不含照片、文件名、路径、挂载名、EXIF、拍摄时间或原始自由文本。
4. 当前正式结果再次导出时沿用原回执。切单、过期完成、失败和取消不留下可误认为新结果的用片明细。
